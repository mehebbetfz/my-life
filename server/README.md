# My Life API (заготовка)

Бэкенд можно развернуть на том же сервере, что и `top-academy-learn`
(Docker Compose / отдельный контейнер).

Пока приложение работает **офлайн** (AsyncStorage на телефоне).
Когда понадобится синхронизация между устройствами — здесь появится:

- `GET /health`
- `GET/PUT /sync` — цели, привычки, задачи
- простая авторизация (один пользователь / токен)

Стек на выбор: Node (Fastify/Express) или тот же стек, что у learn-проекта.
